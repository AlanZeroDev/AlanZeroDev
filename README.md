## Proyecto principal

### Stockeame — Full Stack Inventory Management System

**Stockeame** es una aplicación web Full Stack de gestión y control de inventarios, diseñada para facilitar la administración de productos, registrar conteos físicos y detectar diferencias entre el stock registrado y el real.

**Funcionalidades previstas:**

- Gestión de productos y sectores.
- Registro de conteos de inventario.
- Detección de faltantes y sobrantes.
- Dashboard con métricas y estadísticas.
- Autenticación de usuarios.
- Historial de movimientos y conteos.
- Importación de archivos Excel en futuras versiones.

**Stack previsto:** React, TypeScript, Python, FastAPI, PostgreSQL y Docker.

**Estado:** En desarrollo.

[Ver repositorio de Stockeame](https://github.com/AlanZeroDev/Stockeame)
