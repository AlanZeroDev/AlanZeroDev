## Proyecto principal en desarrollo

###  PulsoStock

Sistema web de gestión y control de inventario para pequeños comercios.

Permitirá registrar productos y categorías, cargar compras, realizar ventas y actualizar automáticamente las existencias. También contará con alertas de stock bajo, estadísticas comerciales y controles de inventario físico frente al stock registrado en el sistema.

**Tecnologías planeadas:** React, FastAPI, PostgreSQL, API REST y Docker.

**Estado:**  En desarrollo
